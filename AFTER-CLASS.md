# AI Foundations 101 — After-Class Follow-Ups

Use only approved, non-sensitive material.

1. **Read:** [How Claude Code works](https://code.claude.com/docs/en/how-claude-code-works), then identify the context, tools, actions, and verification in the agentic loop.
2. **Try:** Complete one contained task using Goal, Data and tools, Context, Output, and Manual verification; save both the artifact and its evidence card.
3. **Make it stick:** Read [How Claude remembers your project](https://code.claude.com/docs/en/memory), then add three concise instructions you would otherwise repeat to your project guidance.
