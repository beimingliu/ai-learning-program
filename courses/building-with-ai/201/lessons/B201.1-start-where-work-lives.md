# B201.1 — Start Where Your Work Lives

**Duration:** 2–3 minutes  
**Audience assumption:** The learner completed or placed out of Foundations 101  
**Key concept:** A bounded workspace makes the right material reachable and the operating scope visible.  
**Learner outcome:** Open and verify the correct folder, project, attachment, or approved application surface.

## A-roll script

Welcome to the Analytics AI Enablement education series. Today in Building with AI, we focus on starting where your work lives.

When an agent cannot find a file, the problem is often not intelligence. It is location. Practical work begins by putting the agent beside the material it needs and confirming the boundary.

Use the approved surface that creates the least friction. In a terminal, `pwd` shows the current folder, `ls` shows its contents, and `cd folder-name` moves to the intended project before you start the agent. In an approved Desktop or IDE surface, open the project or attach the exact files. In an application connection, confirm the account, workspace, and object you intend to inspect.

Now ask a read-only orientation question:

> State the current workspace. List the files or resources likely relevant to this task. Do not open unrelated areas and do not change anything.

Compare that answer with what you can see. Confirm three things: the source is present, the destination for a new artifact is clear, and the workspace does not expose a broader area than the task needs.

The workspace makes files reachable; it does not mean every file is already in context. Ask the agent to inspect named sources before relying on them.

The terminal is optional, not a badge of seriousness. Choose the approved route that lets you see scope and review work. If an attachment, cloud system, or browser surface changes where execution occurs, confirm that with your organization before using sensitive material.

Your action is to open the real location for one recurring task and capture a one-line workspace check: source, output destination, and boundary.

- Box the source, output destination, and boundary.

## Immediate exercise and feedback loop

Run the orientation prompt. A peer should be able to locate the same source from your description without asking where it is.

## Boundary

A visible workspace does not automatically authorize every file in it or load every file into context.
