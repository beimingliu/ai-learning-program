# B201.2 — Files, Tools, and MCP in Practice

**Duration:** 2–3 minutes  
**Audience assumption:** The learner can open and verify a bounded workspace  
**Key concept:** Operate the narrowest approved route that can retrieve the needed information.  
**Learner outcome:** Complete a read-only retrieval through a local file, existing tool, or approved MCP connection.

## A-roll script

Welcome to the Analytics AI Enablement education series. Today in Building with AI, we focus on files, tools, and MCP in practice.

Foundations gave you the choice: local file, existing tool, or MCP. Now make that choice operational.

Write the smallest result you need. For example: “Return the available fields and at most five records from last week's approved tickets.” Then inspect the routes available in `[APPROVED CLAUDE CODE SURFACE]`.

If a current export is already approved and sufficient, attach or open the file. If an existing built-in or command-line tool can retrieve the data reliably, ask the agent to show the exact read-only command or action before running it. If repeated work needs live structured access, open the MCP or connector panel, confirm `[APPROVED MCP OR CONNECTOR]`, and inspect the tools or resources it exposes.

Before any run, name five boundaries: which account or workspace, which resource, which fields, how many records, and whether the capability is read-only. Then ask:

> Use only this approved route. Return the requested fields and at most five records. Do not create, update, or delete anything. State which tool or resource you used.

Compare the returned field list or sample with the source system. If the system offers more capability than the task needs, do not use it merely because it is available.

Credentials and external content deserve attention. The connection acts with the credential scope it receives, and retrieved content enters context. Least privilege and data policy still apply.

Your action is to complete one narrow read-only retrieval and record the route, scope, and evidence that it reached the intended source.

## Boundary

An approved connection can still be too broad for a particular task, and a successful call does not establish output correctness.
