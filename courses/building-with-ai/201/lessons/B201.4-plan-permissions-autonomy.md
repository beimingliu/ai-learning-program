# B201.4 — Plan, Permissions, and Safe Autonomy

**Duration:** 2–3 minutes  
**Audience assumption:** The learner has a bounded workspace, tool path, and model choice  
**Key concept:** Match autonomy to task familiarity, reversibility, and potential impact.  
**Learner outcome:** Choose a permission mode, action boundary, and review point for a real task.

## A-roll script

Welcome to the Analytics AI Enablement education series. Today in Building with AI, we focus on planning, permissions, and safe autonomy.

Autonomy is not one switch. Permission modes change which actions the agent can take before asking you.

In current Claude Code documentation, **Manual** asks before file edits and shell commands. **Plan** allows exploration and a proposed approach without editing source files. **Accept Edits** permits file edits and common filesystem actions while still asking for other commands. Some environments also expose **Auto**, which evaluates actions with background safety checks. Your approved interface and policy are the source of truth.

Choose with three questions. Do I understand the task and expected result? Can I reverse the changes? What is the impact if the agent acts incorrectly?

For an unfamiliar analysis or change, begin in Plan. Review the sources, proposed steps, output location, checks, and stop condition. For a familiar, local, version-controlled edit, a mode that accepts edits may reduce interruptions—but you still inspect the diff and run checks. For an external write, production action, sensitive source, or ambiguous outcome, use the most conservative approved mode and require a human decision before execution.

Separate guidance from control. A prompt or project instruction influences what the model tries. Permissions, access controls, hooks, and policy determine what the system allows. Copies, version control, or a sandbox improve recovery but do not make a bad action correct.

Your action is to write one sentence: “Use ___ mode because the task is ___, changes are ___ to reverse, and the impact is ___.” Add the exact point where the agent must stop for review.

## Immediate exercise and feedback loop

Open the mode selector, choose conservatively, and have a peer challenge the choice by changing one risk factor.

## Boundary

Higher autonomy reduces prompts; it does not improve task definition, correctness, or governance.
