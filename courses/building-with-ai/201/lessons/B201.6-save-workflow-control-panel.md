# B201.6 — Save the Workflow and Use the Control Panel

**Duration:** 2–3 minutes  
**Audience assumption:** The learner has completed one controlled, verified work run  
**Key concept:** A useful session becomes repeatable when inputs, controls, checks, ownership, and recovery are saved as a workflow.  
**Learner outcome:** Save a reusable recipe and locate the controls needed to rerun it.

## A-roll script

Welcome to the Analytics AI Enablement education series. Today in Building with AI, we focus on saving the workflow.

One successful session is useful. A maintained workflow changes how work gets done.

Open a verified session and ask the agent to extract a one-page recipe. It must include the trigger, owner, last-tested date, inputs, required context, approved tool route, model and effort guidance, steps, expected output, independent checks, human decision, and recovery or escalation path. Remove temporary details that will change next week.

Save the recipe in `[SHARED WORKFLOW LOCATION]` or an approved personal workflow folder. On the next run, begin by confirming the inputs and environment, then ask the agent to propose the plan from the recipe. Do not assume last month's schema, permissions, or connector still applies.

Use the product's control panel to inspect the environment instead of memorizing volatile commands. In current Claude Code interfaces, the slash menu and related controls can answer: What can the product do? What can it act on without approval? What is consuming context? Which MCP servers are connected? Which model and effort are active? How do I compact or start fresh? Demonstrate the exact controls in `[APPROVED CLAUDE CODE SURFACE]` before release.

Project instructions or memory may preserve stable guidance. A workflow or skill preserves a procedure. Permissions and policy enforce boundaries. Keep these roles separate.

The boundary is drift. Inputs, business definitions, model behavior, tool connections, and policies change. A reusable workflow always has an owner and last-tested date.

Your action is to complete the reusable workflow recipe, locate the relevant controls in your approved interface, and schedule the next real run.

## Immediate exercise and feedback loop

Give the recipe to another learner. It passes when they can locate the inputs, run conservatively, perform the checks, and identify the human decision without the original conversation.

## Boundary

A saved workflow is a maintained operational asset, not a permanent guarantee that the environment or output remains correct.
