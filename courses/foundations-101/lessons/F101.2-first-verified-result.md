# F101.2 — Turn a Prompt Into a Verified Analysis

**Duration:** 3 minutes 38 seconds (published cut; script estimate was 3:41)  
**Timing basis:** 135 spoken words per minute  
**Production audio:** 218-second local Qwen3-TTS cloned-voice track, generated section by section  
**Audience assumption:** The learner completed F101.1 and can use an approved AI agent to read local files and create a new file  
**Key concept:** Do not hand a complex analysis to AI as one uninterrupted task. Explore, plan, build, inspect, and validate the work together.  
**Learner outcome:** Guide an AI agent through a real dataset, review its plan and implementation, independently check the output, and decide whether the analysis is complete.

## A-roll script

(0:00–0:10) | Series Introduction

Welcome to the Analytics AI Enablement education series. Today in Foundations, we'll use Claude Code to build and verify a real analysis.

(0:10–0:41) | Do Not Start With the Final Ask

Prompting defined goal, data and tools, context, output, and manual verification. Here, those responsibilities guide a working conversation. AI can solve this exercise in one shot, but that is not the point here. Start by asking, “What's in this folder? Do not write code yet.” If the agent starts implementing anyway, press the `Escape` key to stop it early. You set the pace and correct assumptions before they spread.

(0:41–1:09) | Understand the Task

Feel free to download the F101.2-jaffle-shop folder and do the analysis along with the video. It contains two CSVs, README.md, and metric-definitions.md. Instruct the AI to read the README, and ask, “What's the task?” The agent should explain the deliverable: analyze completed-order payments and create an HTML report. Confirm the sections and business rules before code is written. Confirm that *you* understand the assignment.

(1:09–1:36) | Inspect the Data

Now ask, “Tell me more about the two CSVs.” Review the real columns and a few rows. Orders contain an ID, date, and status. Payments contain an order ID, payment method, and amount in cents. Notice that some orders have multiple payments. This inspection tells you what must be joined, filtered, and converted. Ask when a field or relationship is unclear.

(1:36–2:00) | Agree on a Plan

Then ask the agent to plan the work. Claude Code also has Plan Mode, which separates planning from execution; we'll cover it later. The plan should load both files, keep completed orders, join by order ID, convert cents, calculate both breakdowns, generate the report, and verify the result. Read it and correct missing rules before continuing.

(2:00–2:20) | Let the AI Build a First Pass

When the plan makes sense, say, “Go ahead.” Let the agent create the calculation code and the HTML report. Watch which files it writes and which commands it runs. Treat the result as a first pass, even if the agent says the work is complete.

(2:20–2:53) | Validate Independently

Use a sub-agent with fresh context to recalculate the source files and compare its result with the HTML. This gives you a second check without inheriting the first agent's assumptions. We'll cover both concepts in a later video. The expected result is sixty-seven completed orders and one thousand one hundred three dollars. By month, that is four hundred twenty-four, four hundred, and two hundred seventy-nine dollars. If the breakdowns differ, the report is not finished.

(2:53–3:15) | Inspect and Correct the HTML

Open the HTML in a browser. Check the headline, chart labels, payment-method table, observations, and calculation section. Trace one known record: order two is completed and contributes twenty dollars. Ask the agent to fix any mismatch and remove conclusions the files cannot support. Then reopen the report and check again.

(3:15–3:32) | Decide Whether It Is Complete

The work is complete only when the source, calculations, and visible report agree, and *you* can explain how the result was produced. The AI can build quickly. You remain accountable for deciding whether the work is ready.

(3:32–3:41) | Continue Learning

Explore other videos in this series, and leave a comment in the Analytics AI knowledge sharing channel so we can improve the course.

## Prompts used in the lesson

1. `What's in this folder? Do not write code yet.`
2. `Open F101.2-jaffle-shop/README.md and explain the exercise, deliverable, and business rules. Do not write code.`
3. `Tell me more about the two CSVs. Show the columns, a few representative rows, and anything that could affect the analysis.`
4. `Plan your work. What are you going to do for this report? Include how we will verify the result.`
5. `Go ahead and create the first pass.`
6. `Start a sub-agent with fresh context. Recalculate the totals from the source files and compare them with every number shown in the HTML.`
7. `Open the report, trace order 2, and fix any mismatch or unsupported conclusion. Then summarize what you checked.`

## Immediate exercise and feedback loop

Download [the F101.2 Jaffle Shop exercise folder](../exercises/F101.2-jaffle-shop/README.md), including `raw_orders.csv`, `raw_payments.csv`, `README.md`, and `metric-definitions.md`. Work through the analysis offline with an approved AI agent using the seven staged prompts above. Do not let the agent implement until you understand the task, the data, and its plan.

Treat the generated HTML as a first pass. Outside the report, reproduce the headline value, reconcile the monthly and payment-method values, trace order 2, and inspect the visible HTML. Revise the report until the source data, calculations, and presentation agree.

## Expected verification

- Completed orders: **67**
- Completed-order payment value: **$1,103**
- Monthly reconciliation: **$424 + $400 + $279 = $1,103**
- Order 2: **completed**, **2,000 cents**, **$20**

## Boundary

This synthetic dataset can teach the workflow, but it cannot explain customer behavior or establish causality. The selected checks test important parts of the analysis; they do not prove that every line of the report is correct.
