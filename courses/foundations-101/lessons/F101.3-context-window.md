# F101.3 — Context Window in AI Agent

**Duration:** 4 minutes 4 seconds  
**Timing basis:** 136 words per minute, section gaps 0.8s (1.0s before Continue Learning)  
**Audience assumption:** The learner has produced one verified artifact and has seen an agent read sources, build an output, and be corrected  
**Key concept:** The harness rebuilds the model’s view every step; context is that view, not the world itself.  
**Learner outcome:** Recognize when a session's context has drifted, and act on it before the output does.

## A-roll script

(0:00–0:09) | Series Introduction

Welcome to the Analytics AI Enablement education series. Today in Foundations, we focus on the context window in AI agents.

(0:10–0:52) | Why It Forgets

You have heard the word "Context" many times by now. But how does it affect your work? Why should you care? And how are you supposed to manage it?

If you have used Claude Code for a while, you probably have watched it be forgetful. It uses the wrong version of a dataset. It quietly drops the two-line filter you added after an upstream change. It puts a number in the wrong column of your deck.

Most of the time the AI is capable of the work. It just needed a nudge, or a requirement stated explicitly.

(0:53–1:25) | What the Harness Is Doing

An agent is a model plus a harness. The harness supplies the system prompt, the tools, the loop, and the translation layer between them. The model predicts the next token. The harness decides where the model gets to look, and what it is allowed to do next.

Which means context is not what the model learned in training and stored in its weights. Context is its current view of the world.

(1:26–2:03) | What the Model Can Actually See

So the two words in this lesson's title are not the same thing.

**Context** is what is already loaded: the system prompt, the tools and MCPs it can reach, the conversation so far, and the files and data you have shared. A file sitting in your folder is not in context. Something has to read it first.

**Memory** is what Claude decides is worth keeping: a writing style you prefer, a definition you corrected three times, written down so a future session starts already knowing it.

(2:04–3:25) | When They Drift Apart

Two things often go wrong in practice.

First, context fills up. Steer the same session enough times and a data analysis will eat the window fast. My own tell is around sixty percent. That is when replies start coming back as “You're absolutely right,” “That's a great catch,” “You've identified the key issue here.” When you see that, you have two options, and they are usually not interchangeable. Compacting keeps a summary of the work so far, so use it when the analysis is on track and you just need room to keep going. Start a new session when the work has gone wrong more than once, because compacting could carry the wrong assumption forward in the summary as if you had confirmed it.

Second, the truth changed and the agent does not know. You settle a definition with a stakeholder, or a manager redirects an implementation. Claude is still working from the version you agreed on last week.

Which brings back the point from the last lesson. You are still accountable for the work, whether you produced it or the AI did.

(3:26–3:53) | How Do You Manage It

Four habits.

1. Keep the context window under 50 percent when possible.

2. If a project definition, a requirements doc, or a set of meeting notes is the source of truth, point the agent at those files before the analysis begins, not after.

3. Treat “You're absolutely right” as a signal to start a new session.

4. And verify the output yourself.

## Immediate exercise and feedback loop

For one real task, write down three things: the sources it touches, the part that must be loaded into context before the work starts, and the definition worth persisting as memory. A reviewer should be able to challenge any source you would load that the task never needed.

## Boundary

This lesson describes what the harness does, not how to operate it. Memory is persisted guidance loaded into context—not guaranteed truth, access control, or enforcement. Where that guidance lives is F101.4. Operating the harness—permissions, controls, and recovery—is Building with AI 201.
