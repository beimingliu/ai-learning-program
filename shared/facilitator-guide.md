# Facilitator Guide

Use the [wording and content reference](wording-content-reference.md) when writing, recording, or revising lesson scripts.

## Delivery model

Foundations 101 is the shared entry point. After its capstone, learners select either Building with AI 201 or AI Thinking 201. Do not describe one 201 course as advanced preparation for the other.

Each lesson follows the same rhythm:

1. Name the friction without shaming the learner.
2. Teach one sentence-sized concept.
3. Show a source, an action, and a check.
4. State the boundary.
5. Pause for the learner's immediate action.

## Demonstration setup

- Use an approved, non-sensitive CSV, document, or repository.
- Keep the source unchanged; create new outputs.
- Show the actual source, the agent action, and independent verification.
- Start read-only before enabling write-capable tools or connections.
- Offer the approved Desktop or IDE route so terminal comfort is not an entry requirement.
- Replace every bracketed organization placeholder before release.

## Feedback loops

Do not continue merely because a video ended. Ask the learner to show the observable action: a row-count reconciliation, a five-part task brief, a permission choice with a reason, a corrected failure diagnosis, or a completed canvas. Give feedback against the lesson outcome and boundary.

## Lesson QA

Score 0–2 for each item. A lesson should not ship below 16/20.

- One clear concept.
- Correct track placement.
- Immediate relevance.
- Concrete demonstration or example.
- Explicit boundary.
- Independent learner action.
- No hidden prerequisite from the other 201 course.
- Product claims verified where applicable.
- Reusable artifact or behavior.
- Clear bridge to the next level.

## Accessibility

Use high-contrast captions, describe important visual changes aloud, avoid rapid command sequences, and make every exercise possible with the approved non-terminal surface when product capability permits.
